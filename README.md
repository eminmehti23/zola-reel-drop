# zola-reel-drop

A temporary drop box for Zola Group's Instagram reels.

Instagram's publishing API downloads a reel from a public link. Just before a reel is posted to @zola.group, the posting routine puts that one video here, Instagram downloads it, and the routine removes it again once the reel is live.

Nothing else is kept here: no code, no keys, no other files. The full library of reels lives in a private repository.
